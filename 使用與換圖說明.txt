Gallery v1.0 — 使用與換圖說明
更新：2026-11-18

1. 開啟
直接雙擊 index.html。無須安裝套件或啟動伺服器，可離線閱讀與操作。
resume.html 為精簡履歷，右上角可列印／另存 PDF。
建議使用新版 Chrome、Edge、Firefox 或 Safari。圖片、字體、樣式與程式皆為獨立檔案。
搬移或分享時請保留整個網站資料夾，不要只傳 index.html。
本次沒有部署、上傳或連接資料庫。

2. 主要檔案
index.html           首頁、學經歷、申請動機與聯絡文字
resume.html          精簡履歷，關鍵文字可在無 JavaScript 時閱讀
css/site.css         首頁配色、排版、動畫與手機版
css/resume.css       簡歷與 A4 列印樣式
js/profile.js        手機、頭像、GitHub 與額外競賽圖片設定
js/profile-view.js   首頁與簡歷共用的個人資訊顯示
js/content.js        10 件作品、作品圖片、獎項與證照
js/site.js           篩選、詳情、圖片放大、導覽與 Email 複製
js/resume.js         簡歷個人資訊與列印
images/             頭像與原有遊戲畫面
images/projects/    作品照片、程式圖與示意圖
assets/             Noto Sans TC 字體與開放字體授權
舊版/               原有版本與歷次說明（可攜 ZIP 不含舊版）
預覽圖/v1.0/        新版的實際檢查畫面（本機保留）

3. 手機號碼與 GitHub
用記事本打開 js/profile.js。
將 phone: '' 改為自己的號碼，例如 phone: '0912-345-678'。
留白時隱藏，填入後自動成為電話連結；首頁、簡歷共用同一設定。
GitHub 有作品後，把 github 改為完整 https://github.com/帳號 網址。
目前兩欄都留白，不會顯示不存在的聯絡資料。

4. 更換頭像
把照片放入 images/，例如 avatar.jpg。
將 js/profile.js 的 avatar 改為 'images/avatar.jpg'，avatarAlt 改為 '林柏翰的個人照片'。
也可用完整 https:// 圖片網址；使用網路圖片時需要連線及來源網站允許載入。
建議尺寸至少 640 × 720，臉部置中，人物上方留一些空間。
目前保留 v0.5 淡紫人物剪影，並非本人照片。
桌面右欄為 170px 相框，手機文字下方為 114px；傾斜、進場淡入與移入轉正沿用 v0.5。
圖片失效時自動回到人物剪影。

5. 更換作品圖片
最簡單：用同名圖片覆蓋 images/projects/ 內的檔案。
更換檔名或副檔名：在 js/content.js 找到作品，修改 cover 與 images 內的路徑。
cover 是卡片封面；images 是詳情及放大圖片清單，每張包含「路徑、替代文字」。
可增減 images 項目，縮圖和上一張／下一張會自動更新。
建議照片寬度 1000–1800px；PNG 適合透明圖與程式截圖，JPG 適合照片。
維持圖片原始比例，不必轉成 HTML 編碼。
換成自己的圖後，也請同步修改描述及「實體作品／程式邏輯示意」標示。

常用對照

images/projects/care-robot-prototype.png    照護機器人原型
images/projects/cpp-puzzle.svg              積木拼圖邏輯示意
images/projects/cpp-chess.svg               象棋規則示意
images/projects/robot-control.svg          感測與控制流程示意
images/app-battle.jpg                       App Inventor 戰鬥畫面
images/c-battle.jpg                         C 文字戰鬥畫面

6. 額外的技能競賽照片
js/profile.js 的 robotImage 可填真實競賽作品照片的相對路徑或 https:// 網址。
填入後會作為「機器人競賽程式」封面與第一張圖片；留白使用控制流程示意。
robotImageAlt 用於圖片描述。歷版 robotImageCaption 設定保留相容，v1.0 圖說使用 robotImageAlt。
不要把其他專題照片標為技能競賽現場照。

7. 更新文字
作品細節、本人工作、工具、獎項、證照：修改 js/content.js。
學校、動機、時間軸、Email：修改 index.html 與 resume.html。
簡歷為人工編排的精簡版，作品或獎項有變時請同步更新 resume.html。
行動通訊實務競賽目前寫「企畫書階段、入圍決賽、12/12 決賽」，賽後請更新狀態。
JavaScript 文字需放在引號內；文字有單引號時改用雙引號或加反斜線。

8. 操作
分類切換遊戲程式、機器人、硬體作品；展開後閱讀全部 10 件。
點卡片開詳情；點縮圖切換，點主圖放大；放大後可用左右方向鍵切圖。
Esc 或「關閉」關掉目前視窗；關閉大圖後仍保留作品詳情。
支援 Tab 鍵與焦點回復；有短進場、捲動進場、卡片移入、篩選與視窗轉場。
沒有額外的動畫開關，仍尊重作業系統的動態效果偏好。
簡歷作品名稱可直接連到首頁對應詳情。

9. 列印
使用 resume.html 的「列印／另存 PDF」。選 A4、100% 比例，關閉瀏覽器額外頁首頁尾。
增加大量文字後請重新查看列印預覽。PDF 是當時資料快照，換圖或改字後須重新匯出。

10. 保留舊版
修改前 v0.6.2 的 HTML、CSS、JS、圖片均已獨立保存。
本機舊版與歷代壓縮檔保留；分享新版請用 Gallery_v1.0_網站.zip。
